Datenschutzerklärung

Stand: 5. November 2026

Locked Site Blocker ist eine Browser-Erweiterung, die Websites sperrt, die du auswählst. Kurz gesagt: Alles, was sie weiß, bleibt in deinem Browser. Es werden keine Daten erhoben oder weitergegeben. Diese Seite gilt für die Erweiterung und für diese Website.

Was die Erweiterung speichert

  • Die Liste der Websites, die du sperrst, und für jede, wann du sie zuerst hinzugefügt hast, wann ihr aktueller Timer begann und wann er endet.
  • Für jede Website auf dieser Liste, wie oft sie aufgerufen und von der Sperre aufgehalten wurde – pro Tag für die letzten 60 Tage und insgesamt. Von den Seiten selbst wird nichts gespeichert, nur die Anzahl, und sie wird gelöscht, wenn du die Website entfernst.
  • Ob du den Inkognito-Hinweis im Erweiterungsfenster geschlossen hast, wann du das Fenster zum ersten Mal geöffnet hast und ob du die einmalige Frage „Hilft dir der Blocker?“ beantwortet oder geschlossen hast.
  • Wann die Erweiterung zuletzt lief (etwa einmal pro Minute und bei jeder Nutzung aktualisiert) und, für die letzten 20 Male, an denen sie ausgeschaltet war, wann sie aus- und wieder eingeschaltet wurde und ob du den Hinweis dazu geschlossen hast.

Diese Daten liegen nur lokal im Erweiterungsspeicher deines Browsers. Sie werden weder mit deinem Google- oder Microsoft-Konto noch mit anderen Geräten synchronisiert.

Was die Erweiterung nicht tut

  • Sie erhebt, überträgt, verkauft oder teilt keine Daten. Sie hat keine Server und stellt selbst keine Netzwerkanfragen.
  • Sie liest, speichert oder verändert keine Inhalte der Seiten, die du besuchst, und führt keinen Browserverlauf (abgesehen von der täglichen Anzahl oben, für Websites, die du gesperrt hast). Die Adresse einer Seite sieht sie nur, wenn du die Website sperren willst, auf der du gerade bist: beim Öffnen des Erweiterungsfensters (für den Ein-Klick-Button; das Tastenkürzel öffnet es ebenfalls) oder über das Rechtsklick-Menü. Die Adresse wird nicht gespeichert, außer du sperrst die Website – dann landet nur ihr Name auf deiner Liste.
  • Kein Konto, keine Werbung, keine Analyse, kein Tracking, kein nachgeladener Code.
  • Die einmalige Frage im Erweiterungsfenster kann Buttons zum Bewerten und zum Unterstützen der Entwicklung zeigen. Sie öffnen nur beim Anklicken die Store-Seite bzw. die Spendenseite in einem neuen Tab; dabei wird nichts über dich übermittelt.

Berechtigungen

  • Websites sperren (declarativeNetRequest): teilt dem Browser mit, welche Websites auf deiner Liste gesperrt werden.
  • Speicher (storage): speichert deine Sperrliste auf deinem Gerät.
  • Rechtsklick-Menü (contextMenus): fügt „Diese Website sperren“ zum Menü hinzu.
  • Alarme (alarms): weckt die Erweiterung etwa einmal pro Minute, damit sie dir später sagen kann, ob und wie lange sie ausgeschaltet war.
  • Service Worker gesperrter Websites entfernen (browsingData): Wenn du eine Website sperrst, entfernt die Erweiterung ihren Service Worker – ein Hintergrundskript, das manche Websites für Push-Benachrichtigungen oder zum Offline-Lesen installieren. Ohne das könnte sich eine solche Website trotz Sperre aus ihrem eigenen Zwischenspeicher weiter öffnen. Sonst wird nichts gelöscht: weder Verlauf noch Cookies, Anmeldungen oder andere Daten der Website. Ihre Push-Benachrichtigungen enden, bis du die Sperre entfernst und die Website wieder besuchst.
  • Zugriff auf alle Websites (<all_urls>): damit der Browser die Countdown-Seite statt einer gesperrten Website zeigen, bereits offene Tabs neu laden und erkennen kann, auf welcher Website der aktuelle Tab ist, wenn du sie sperren willst. Er gilt für alle Websites, weil du entscheidest, welche gesperrt werden.

Daten löschen

Eine Website von der Liste zu entfernen (möglich, sobald ihr Timer abgelaufen ist), löscht sie. Beim Deinstallieren der Erweiterung werden alle ihre Daten aus deinem Browser gelöscht.

Diese Website

  • Die Website setzt keine Cookies, nutzt keine Analyse und kein Tracking und lädt keine Schriften oder Skripte von anderen Diensten.
  • Sie wird über GitHub Pages bereitgestellt, betrieben von GitHub, Inc. (USA). Bei jedem Besuch protokolliert GitHub aus Sicherheitsgründen deine IP-Adresse, wie bei jeder GitHub-Pages-Website. Mehr dazu in der Datenschutzerklärung von GitHub.
  • Nach dem Deinstallieren der Erweiterung öffnet der Browser die Abschiedsseite. Ihre eine Frage ist freiwillig. Antwortest du, wird nur deine Auswahl übermittelt – ohne Namen, E-Mail-Adresse oder Sperrliste. TODO: Formulardienst nennen, bevor das Formular eingeschaltet wird.
